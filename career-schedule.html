Auto-Fill Unscheduled Routes

Assigns a plausible departure time to every route below that has no schedule entry yet -- biased toward realistic patterns (long-haul flights lean toward early-morning/overnight departures, matching what the real-world AviationStack data actually showed) with built-in variety so routes don't all cluster at the same time. Deterministic: re-running this never changes times already assigned, and it never touches routes you've manually set or suspended.

Career Mode Roster

Career Mode only shows routes in the roster for the month a pilot is actually looking at -- a month with no roster generated yet renders completely blank, it does not fall back to some other month's selection. You can generate this month's roster, or get ahead of a busy month by generating next month's early -- but never further ahead than that, so a month always reflects a deliberate choice, not a stale default. Click Generate to pick a fresh, capped selection from routes that already have a schedule (Auto-Fill those first if needed); re-running it for the same month replaces that month's previous selection. You can also toggle individual routes in the table below by hand for whichever month is selected here.
